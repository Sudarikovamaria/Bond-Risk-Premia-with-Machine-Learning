# Сеть с одним выходом вместо шести

Эксперимент сверх статьи. Проверялось, нужно ли сети предсказывать шесть сроков
независимо, или достаточно предсказывать один общий фактор премии за риск.

## Мотивация

Шесть целевых доходностей почти коллинеарны: корреляция `rx_2` с `rx_3` равна 0.99,
с `rx_10` — 0.82, а **первая главная компонента объясняет 95.5% дисперсии** всех
шести, две первые — 99.6%. Экономически это очевидно: все сроки реагируют на один
и тот же сдвиг кривой, отличаясь множителем, близким к дюрации.

Сеть с шестью независимыми выходами учит шесть отображений там, где по сути нужно
одно, и даёт шесть независимых источников шума в прогнозе.

## Как устроено

1. Фактор — среднее шести избыточных доходностей на каждую дату истории.
2. Сеть (один слой, три нейрона — та же архитектура, что в Panel C) предсказывает
   этот фактор, то есть имеет один выход вместо шести.
3. Нагрузки оцениваются регрессией `rx_n = a_n + b_n * фактор` по той же истории.
   Оценённые `b_n` воспроизводят дюрацию: 0.29 для двухлетних, 1.02 для
   пятилетних, 1.91 для десятилетних. R² этих регрессий от 0.84 до 0.99.
4. Прогноз по срокам: `rx_n = a_n + b_n * фактор_прогноз`.

И фактор, и нагрузки считаются только по данным до даты прогноза.

## Результаты

R²_oos в процентах, 348 прогнозов, сырые цели:

| | rx² | rx³ | rx⁴ | rx⁵ | rx⁷ | rx¹⁰ | EW |
|---|---|---|---|---|---|---|---|
| шесть выходов (базовая) | −38.6 | −9.4 | +0.4 | +4.5 | +3.0 | −0.5 | +3.8 |
| **один выход** | −0.1 | +6.2 | +10.0 | +12.6 | +14.7 | **+17.3** | **+13.9** |
| статья | 12.7 | 16.4 | 19.5 | 21.6 | 23.1 | 26.4 | 23.0 |

p-value Кларка-Уэста от 0.004 до 0.035, то есть значимо на всех сроках; у базовой
версии значимости не было нигде. Корреляции прогноза с фактом монотонно растут со
сроком, с 0.21 до 0.35, чего у базовой версии тоже не наблюдалось — там они были
плоскими около 0.2 без структуры.

Со стандартизованными целями улучшение сохраняется, но слабее: портфель растёт с
+0.9% до +3.7%. То, что эффект есть при обоих вариантах масштабирования, —
основной аргумент, что это не случайность конкретного прогона.

## Оговорки

Прогоны сделаны на 10 сидах с отбором лучших 3, а не 100 с отбором 10, как в
статье. Усреднение по сотне сетей уберёт часть шума прогноза и, скорее всего,
поднимет R² ещё, но при корреляции около 0.3 потолок всё равно заметно ниже
опубликованных 23-26%.

Всё посчитано с `GAP=1`, то есть внутри схемы статьи вместе с её заглядыванием
вперёд. На линейных моделях переход к честному зазору стоил 15-20 процентных
пунктов, на градиентном бустинге с агрессивными настройками — 113. Сколько из
+17.3% переживёт `GAP=12`, пока не проверено, и до этой проверки число нельзя
приводить как результат.

Выбор сырых целей против стандартизованных сделан после того, как стали видны
R², то есть по тестовой выборке. Защитимая формулировка — «один выход улучшает
результат при обоих вариантах масштаба», а не «сырые цели дают 13.9%».

## Запуск

Скрипт оборачивает сеть из Panel C и ожидает `NN_1layer_3nodes.py` рядом с собой,
вместе с файлами данных, которые тот читает. Аргумент `std` включает
стандартизацию целей:

```bash
python run_single_output.py        # сырые цели
python run_single_output.py std    # стандартизованные
```
